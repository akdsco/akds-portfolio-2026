# logo flare

- Date: 2026-07-17 15:12
- Branch: logo-flare

## Problem / Context

The nav wordmark does one thing on hover today: `text-faint` brightens to
`text-ink`. Owner wants an easter egg on top of it. Dwell on the logo (1s) and
the four letters flare coral (`--hi`) left to right, each lighting and lifting
slightly, dropping back as the next takes over. One sweep per dwell, then it
rests at hover ink until the pointer leaves and returns (decided: not looped).

Two constraints found while reading the code, both of which shape the design:

1. **The lift fights the crop.** `Wordmark` is a `0.67em` box with
   `overflow: hidden`, text flush at offset 0, bottom of the glyphs cut by the
   nav's bottom border. A naive `translateY(-2px)` slides a letter's top out of
   the box and decapitates it. It does not read as a lift.
2. **Staggering needs per-letter spans, and splitting text drops kerning across
   the boundaries.** `lib/wordmark.ts` exists precisely so the nav, footer and
   social card cut an identical mark; a sub-pixel drift in the nav alone is the
   "looks like a mistake" failure that file is there to prevent.

## Plan

Pure CSS keyframes plus one dwell timer. No `motion`: this is a staggered
keyframe sweep, which is the CSS-first case.

- **Lift headroom.** Extend the clip box upward by `WORDMARK_LIFT` and push the
  text down by the same amount at rest. Rest state then renders identically (the
  bottom cut does not move) and the lift animates `translateY(lift)` to `0` with
  room to travel. Expressed as a ratio of font size and parked in
  `lib/wordmark.ts` next to `WORDMARK_VISIBLE`, for the reason that file gives:
  one number, three surfaces.
- **`font-kerning: none`** on the mark in every surface, so the split and unsplit
  renders agree by construction rather than by luck. Verify by measuring nav vs
  footer width in the browser.
- **Opt-in `animated` prop** on `Wordmark`. Only the nav passes it, only it
  renders the four spans (each carrying `--i`). The footer keeps its single text
  node. Satori builds its own layout in `lib/og-card.tsx` and never sees this.
- **Colour holds under the sweep for free**: keyframes run ink to hi to ink with
  `fill-mode: both`, so an un-started letter is frozen at ink through its delay,
  which is already the hover colour. Nothing flickers back to `faint` mid-sweep.
- **Timing**: ~360ms per letter (fast up into coral, slower settle), staggered
  180ms so letter N drops back as N+1 lights. Full sweep ~900ms.
- **Guards, both read at event time** (never at render, per the hydration rule):
  skip on `prefers-reduced-motion`, and skip unless `(hover: hover) and
  (pointer: fine)`, since a press on touch fires `pointerenter` too.
- **Restart** needs the animation torn down and re-added, so the letter spans are
  keyed off a run counter to force a remount.

## Increments (test-first)

1. test: `animated` renders 4 spans carrying `--i` 0..3 while plain renders one
   text node; clip box keeps its bottom edge and gains exactly `WORDMARK_LIFT` of
   headroom, with the text offset down to match → impl: `WORDMARK_LIFT` in
   `lib/wordmark.ts`, headroom + `animated` prop in `components/wordmark.tsx`.
2. test: dwell hook under fake timers — arms at DWELL_MS; no arm if the pointer
   leaves at 2999ms; leave mid-sweep resets; coarse pointer never arms; reduced
   motion never arms → impl: `lib/use-dwell.ts`.
3. test: nav wiring — `data-wave` absent at rest, present after a dwell, gone
   after leave → impl: wire `use-dwell` into `components/site-nav.tsx`.
4. verify (no unit surface; keyframes do not run in jsdom): `wordmark-flare`
   keyframes in `app/globals.css`, inside the existing
   `@media (prefers-reduced-motion: no-preference)` block. Checked visually in
   Chrome across both themes, plus a nav-vs-footer width measurement confirming
   the split did not shift the mark.

## Notes

- `--hi` is the coral token (`app/theme.css`), defined for light and dark.
- Nav bar is 56px against the mark's ~25px, so growing the clip box upward has no
  layout cost; the header's own `overflow-hidden` keeps the bleed tidy.
